Project Overview

Award-winning civic technology platform that promotes political literacy and combats misinformation in Philippine politics through interactive features, verified information, and AI-powered assistance.

🏆 Hackathon Achievement & Impact

2nd Place Winner at DLSU SIKAPTala 2025 Hackathon, competing against innovative tech solutions addressing societal challenges. CIVIX stood out for its comprehensive approach to political education and misinformation detection in the Philippines.

The platform addresses critical issues in Philippine democracy: voter education, political accountability, and the spread of misinformation during election cycles, providing citizens with tools to make informed political decisions.

CIVIX is a comprehensive full-stack civic technology platform built with React and Node.js, featuring a Firebase-powered backend and OpenAI GPT-4o-mini integration. The application provides Filipino citizens with verified politician profiles, interactive misinformation detection games, AI-powered political Q&A, and community-driven fact-checking capabilities.

The platform emphasizes user verification through ID validation, ensuring credible community participation while delivering responsive design across desktop and mobile devices. With features like 5-star rating systems, voting history tracking, and real-time political education, CIVIX empowers citizens to engage meaningfully with Philippine democratic processes.

System Architecture & Technical Implementation

Modern full-stack architecture with React frontend, Node.js backend, and Firebase cloud services integration

⚛️ React Frontend

Modern React 18 application with functional components, hooks, and Context API for state management. Implements responsive design with Tailwind CSS and mobile-first approach.

🚀 Node.js Backend

RESTful API server built with Express.js, featuring modular route handling, middleware integration, and comprehensive error handling for scalable backend services.

🔥 Firebase Integration

Firebase Admin SDK for secure server-side operations, Firestore for data storage, and Firebase Authentication for user verification and identity management.

🤖 OpenAI GPT-4o-mini

AI chatbot integration through OpenRouter API with conversation history, context-aware responses, and specialized Philippine political knowledge prompting.

📱 Responsive Design

Mobile-first responsive design with Tailwind CSS, optimized for all screen sizes, touch interactions, and cross-browser compatibility including iOS Safari.

🔐 Security & Verification

User identity verification system with ID document upload, secure API endpoints, CORS configuration, and environment variable protection.
