Project Overview

The Eskwelabs Blog Post Generator is an AI-powered content creation platform that helps users generate SEO-optimized blog posts through a structured, multi-stage workflow, leveraging OpenAI's language models, vector databases, and web scraping to create contextually relevant content based on existing blog data.

🎯 Project Purpose & Context

Developed during my Education Innovation Fellowship at Eskwelabs to address the challenge of scaling content production while maintaining brand voice consistency across multiple writers and diverse educational topics.

The platform enables even non-technical team members to create professional blog posts in minutes by referencing existing Eskwelabs content and automatically adapting to different writers' brand tone and voice patterns.

Built as a full-stack solution with FastAPI backend and Streamlit frontend, the platform processes multiple document formats (PDF, DOCX, images, spreadsheets) through computer vision and NLP, stores content in Qdrant vector database, and delivers production-ready blog posts with integrated SEO optimization and performance analytics.

The system maintains consistent writing styles across team members through semantic embeddings and intelligent content retrieval, resulting in an 80% reduction in blog production time while increasing output capacity by 3x.

System Architecture & Technical Implementation

Comprehensive end-to-end solution featuring advanced AI workflows, vector databases, and multi-modal processing capabilities

🔍 RAG Pipeline

Qdrant vector database with semantic chunking, OpenAI embeddings (text-embedding-3-small), and MMR retrieval for context-aware content generation

🤖 Multi-Model LLM Integration

Dynamic model selection (GPT-4o-mini, o3-mini, Claude) with advanced prompt engineering and structured output parsing

📄 Document Processing Engine

Multi-format support using PyPDF2, python-docx, pandas for Excel, plus GPT-4-Vision for image analysis and content extraction

🌐 API Architecture

RESTful FastAPI backend with multipart form data handling, file upload processing, and secure API key management

🎯 Content Intelligence

Automated web scraping with Firecrawl, real-time vectorstore updates, and metadata-driven content filtering by author/category

📊 SEO Analytics Engine

Textstat integration for readability scoring, keyword density analysis, and AI-powered optimization suggestions
